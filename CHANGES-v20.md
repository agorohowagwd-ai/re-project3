# v20 — что исправлено

1. **Безопасность оплаты.** `/api/payment/callback` раньше верил параметрам в URL: любой мог открыть ссылку с `status=SUCCESS` и получить бесплатный доступ/AI. Теперь callback только указывает, какой заказ перепроверить, а статус и сумма берутся напрямую у Сбера (`getOrderStatusExtended.do`).
2. **Цена на сервере.** `/api/requests` брал цену из браузера — можно было создать заявку за 100 ₽. Теперь цена берётся из `lib/services.ts`.
3. **Сборка.** `app/api/messages/route.ts` использовал `getSupabaseAdmin` без импорта → сборка на Vercel падала на TypeScript / ответ дизайнера не работал. Исправлено.
4. **Скачивание материалов.** Ссылки `<a href>` не передавали токен входа → всегда 401. Теперь `DownloadButton` (fetch + токен). Кнопки есть и на странице материала, и в кабинете → «Материалы».
5. **Перевод по номеру Сбера.** Пока нет `SBER_USERNAME/SBER_PASSWORD`, оплата идёт переводом на `MANUAL_PAY_PHONE` с уникальным кодом-комментарием; владелец подтверждает в `/admin → Оплаты → «Деньги пришли»`, после чего доступ/заявка активируются.
6. **Кабинет → Оплата.** Раньше платил «абстрактные 2000 ₽» без заказа. Теперь показывает неоплаченные заявки.
7. `next.config.js`: `outputFileTracingIncludes` перенесён в `experimental` (для Next 14), иначе файлы `content/education` могли не попасть в serverless-функцию на Vercel.
8. Удалён `public/payment/sber-phone-qr.png` (QR кодировал неверный номер `+789779166565`, нигде не использовался), `tsconfig.tsbuildinfo` добавлен в `.gitignore`, `@vercel/*` закреплены вместо `latest`.

**После обновления:** заново выполните `supabase-schema.sql` не нужно (схема не менялась). Добавьте в Vercel `MANUAL_PAY_PHONE` (опционально) и сделайте Redeploy.

## AI-генерация только от администратора
- `/api/generate` теперь доступен **только роли `admin`** (клиенты получают 403). Ключ OpenAI тратится только когда вы нажимаете кнопку.
- Клиент: загружает фото + пожелания → создаётся заявка (`/api/requests`), фото сохраняется в приватное хранилище (`/api/requests/source`, AI не вызывается) → оплата.
- Админ: `/admin → AI-заявки`: видит исходное фото, стиль, пожелания и статус оплаты, может добавить свои указания и нажать «Сгенерировать». Для неоплаченной заявки спрашивает подтверждение.
- Результат сохраняется в папку клиента и сразу виден в его кабинете; клиенту автоматически уходит сообщение в чат.
- Исправлена ошибка: формы читали `data.id`, а API возвращал `{request:{id}}`, поэтому оплата не привязывалась к заявке. Теперь API отдаёт и `id`, и `request`.
- Серверный каталог цен дополнен для `architecture`, `apartment-project`, `house-project`.
