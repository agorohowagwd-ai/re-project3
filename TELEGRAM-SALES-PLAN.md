# re:project — Telegram + сайт + оплата

## Архитектура v1

**Telegram-канал → карточка продукта на re:project → оплата на сайте → защищённая выдача файла → личный кабинет.**

Это базовый сценарий для цифровых материалов. Telegram здесь является каналом продаж и контента, а сайт — единым местом каталога, оплаты и доступа.

## Что сделать на сайте

1. У каждой карточки Education — кнопка «Купить».
2. До оплаты показывать точный состав: PDF, XLSX, Archicad setup и т. п.
3. После успешной оплаты создавать `payments.status=paid`.
4. Для цифрового продукта выдавать `education_access` и защищённую ссылку на скачивание.
5. В личном кабинете показывать купленные продукты и историю платежей.
6. Для администратора — список продаж, продукт, сумма, дата, Telegram/UTM-метка.

## Telegram v1

Пост: проблема → фрагмент страницы/таблицы → кому подходит → что получает покупатель → цена → кнопка/ссылка на страницу товара.

Пример CTA:

> Полный рабочий набор — на re:project. Посмотреть состав и купить → [ссылка на товар]

## UTM

Для каждого поста используйте отдельную метку, например:
`?utm_source=telegram&utm_medium=post&utm_campaign=education_01`

Так можно видеть, какие публикации приводят к покупке.

## Telegram-бот позже

Если понадобится полноценный магазин внутри Telegram, можно сделать bot/mini app: каталог → карточка → invoice → успешная оплата → выдача доступа на сайте. Для **цифровых товаров, продаваемых внутри Telegram**, Telegram требует Telegram Stars (`XTR`), а не сторонний эквайринг. После успешной оплаты бот должен обработать `successful_payment`, сохранить `telegram_payment_charge_id` и выдать товар.

Поэтому Sber/эквайринг оставляем для сайта, а Telegram Stars — только для отдельного нативного checkout внутри Telegram.

## Что не делать

- Не отправлять платные PDF просто файлом в открытом канале.
- Не хранить постоянную публичную ссылку на файл.
- Не делать цену только в Telegram-посте без карточки товара на сайте.
- Не обещать автоматическую оплату, пока реальный эквайринг не протестирован.

## Этапы запуска

### Этап 1
Сайт + Sber acquiring + защищённая выдача.

### Этап 2
Telegram-канал, шаблоны постов, UTM и ссылки на карточки товаров.

### Этап 3
После первых продаж — bot/mini app со Stars, если нужен нативный checkout.
